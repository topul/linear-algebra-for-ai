- 怎么衡量两个东西"像不像"？（这是搜索、推荐、ChatGPT记忆的核心）

## 一、向量到底是什么？

### 1.1 从"描述一个人"说起

假设你要向计算机描述"小明"这个人，但计算机只懂数字。你会怎么做？

你可能会这样描述：
```
小明：
  身高 = 175
  体重 = 70
  年龄 = 25
  收入 = 8000
```

如果把这4个数字按顺序排成一排：

```
小明 = [175, 70, 25, 8000]
```

**恭喜，这就是一个"向量"。**

> 💡 **向量的本质**：用一串有顺序的数字描述一个东西。
>
> "有顺序"很重要 —— 第1个位置代表身高，第2个位置代表体重，不能乱。

### 1.2 为什么 AI 必须用向量？

**因为计算机只会算数字，不懂"猫"、"国王"、"开心"。**

AI 的核心套路就是：
```
真实世界的东西 → 翻译成一串数字（向量）→ 用数学运算处理 → 翻译回结果
```

举例：
| 真实世界 | 向量（简化版） |
|---------|--------------|
| 一张图片 | 每个像素亮度排成一长串数字 |
| 一个单词"猫" | [0.2, -0.5, 0.8, ...] (300个数字) |
| 你的购物偏好 | [喜欢电子产品:0.8, 喜欢服装:0.3, ...] |

ChatGPT 处理你的问题时，第一步就是把你输入的每个词都变成一个向量。

### 1.3 向量的"维度"

向量里有几个数字，就叫几维。

- `[3, 4]` → **2维**向量（可以画在平面上）
- `[1, 2, 3]` → **3维**向量（可以画在立体空间里）
- `[1, 2, ..., 300]` → **300维**向量（画不出来，但数学上没区别）

**GPT-4 用的词向量是 12288 维。** 你想象不出来12288维空间长什么样，**但这不影响计算** —— 数学规则在任何维度都一样。

## 二、向量怎么"加"？

### 2.1 加法 = 把两件事的影响叠加

最直观的例子：**人在走路**。

你站在原点，先往东走3步，再往北走4步。最终你在哪？

```
第一步的"位移向量" = [3, 0]   （东3，北0）
第二步的"位移向量" = [0, 4]   （东0，北4）

总位移 = [3, 0] + [0, 4] = [3+0, 0+4] = [3, 4]
```

**向量加法规则**：对应位置相加，就这么简单。

```
[a, b] + [c, d] = [a+c, b+d]
```

### 2.2 这在 AI 里有什么用？

**神经网络一层的计算就是"加法+乘法"**：
```
新状态 = 旧状态 + 调整量
```

比如训练时更新参数：
```
新参数 = 旧参数 + 学习率 × 梯度
```
这里"参数"、"梯度"都是向量，相加就是逐元素加。

### 2.3 减法

减法同理：对应位置相减。

```
[5, 8] - [2, 3] = [3, 5]
```

**几何意义**：A - B 这个向量代表"从 B 走到 A 需要的位移"。

> 🎯 著名例子：`vector("国王") - vector("男人") + vector("女人") ≈ vector("王后")`
>
> 这就是 2013 年 Word2Vec 论文震惊世界的发现 —— 向量加减居然能做"类比推理"。

## 三、向量怎么"乘"？这是最关键的一步

### 3.1 第一种乘法：数字 × 向量（标量乘法）

最简单的乘法：一个**数字**乘一个**向量**，就是把每个元素都乘那个数字。

```
3 × [1, 2, 4] = [3, 6, 12]
```

**几何意义**：把向量"拉长"或"缩短"。

- 乘以 2 → 长度变成原来的 2 倍，方向不变
- 乘以 0.5 → 长度变成一半
- 乘以 -1 → 长度不变，方向反过来

**AI 中的用途**：调节强度。比如学习率 = 0.01 乘以梯度向量，就是"小步走"地更新参数。

### 3.2 第二种乘法：向量 × 向量（点积，超重要）

这个稍微抽象，但 AI 里到处都是它。

**计算规则**：对应位置相乘，再全部加起来，得到一个**数字**。

```
[1, 2, 3] · [4, 5, 6]
= 1×4 + 2×5 + 3×6
= 4 + 10 + 18
= 32
```

> 注意：点积的结果是**一个数字**，不是向量！

#### 点积到底有什么含义？

**点积衡量"两个向量有多一致"。**

直觉理解，想象你和朋友各自推一个购物车：
- 你们朝同一个方向用力推 → 车跑得最快（点积大）
- 你们朝垂直方向推 → 车斜着走，效率一般（点积≈0）
- 你们朝相反方向推 → 车不动（点积是负数）

```
向量方向一致  → 点积 大（正数）
向量方向无关  → 点积 ≈ 0
向量方向相反  → 点积 负
```

### 3.3 点积在 AI 中的核心地位

**ChatGPT 的"注意力机制"，核心就是大量的点积运算。**

当 GPT 处理 "猫吃鱼" 这句话时，要决定"鱼"这个词应该多关注前面哪个词。它做的事：

```
鱼向量 · 猫向量  = 较大的数 → "鱼"和"猫"语义相关，多关注
鱼向量 · 吃向量  = 较大的数 → "鱼"和"吃"语义相关，多关注
鱼向量 · 的向量  = 较小的数 → "的"是助词，不太相关
```

**注意力 = 用点积算"应该看哪里"。**

## 四、衡量"像不像"：余弦相似度

### 4.1 为什么直接用点积不行？

点积有个问题：**它受向量"长短"的影响**。

举例：
```
A = [1, 1]       长度短
B = [100, 100]   长度长（但方向一样）

A · B = 100 + 100 = 200   ← 看着很大，但A和B方向完全一样
```

我们想要的是衡量**方向**有多像，**跟长度无关**。

### 4.2 解决方案：除以长度

```
余弦相似度 = (A · B) / (A的长度 × B的长度)
```

这样不管向量多长，结果只反映方向，范围是 `[-1, 1]`：

| 余弦值 | 含义 |
|-------|------|
| 1 | 方向完全一样（最像） |
| 0 | 方向垂直（无关） |
| -1 | 方向完全相反（最不像） |

### 4.3 怎么算"向量的长度"？

用勾股定理推广：每个分量平方，加起来，开根号。

```
向量 [3, 4] 的长度 = √(3² + 4²) = √25 = 5
向量 [1, 2, 2] 的长度 = √(1² + 2² + 2²) = √9 = 3
```

这个长度有个专业名字叫"**L2 范数**"（或"欧几里得范数"），写作 `‖v‖₂`。

### 4.4 这在 AI 里就是"语义搜索"

ChatGPT 怎么"记住"很长的对话？怎么从100万篇文档里找出和你问题最相关的？

**答案：把所有文档都变成向量，用余弦相似度搜索。**

```
你的问题向量 vs 文档1向量 → 相似度 0.92  ← 最匹配，返回这个
你的问题向量 vs 文档2向量 → 相似度 0.45
你的问题向量 vs 文档3向量 → 相似度 0.12
```

这就是"向量数据库"（如 Pinecone、Milvus）的工作原理。

## 五、本节课总结

| 概念 | 一句话理解 | AI 中的用途 |
|-----|----------|------------|
| **向量** | 一串有顺序的数字 | 表示词/图/用户 |
| **维度** | 数字的个数 | GPT-4用12288维 |
| **加法** | 对应位置相加 | 残差连接、参数更新 |
| **标量乘** | 每个元素×同一个数 | 学习率缩放 |
| **点积** | 对应相乘再求和（结果是数字） | 注意力打分 |
| **范数(长度)** | 各分量平方和开根号 | 归一化 |
| **余弦相似度** | 点积 / (两个长度的乘积) | 语义搜索、RAG |
